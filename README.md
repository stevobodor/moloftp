# MoloFTP

**A native FTP, FTPS and SFTP client for Apple Silicon Macs.**

[Website & purchase](https://www.moloftp.com/) · [User guide](https://www.moloftp.com/guide.html) · [Support](mailto:support@moloftp.com)

![MoloFTP showing saved servers, local and remote files, and transfer progress](https://www.moloftp.com/assets/app-window.png)

## Why I built it

I'm Števo, the developer of MoloFTP.

I've been using FTP for years to deliver content to television stations and production companies, and to update websites. It is an old protocol, but it is still part of my working day.

I never found a Mac FTP client that worked quite the way I wanted. So I built Molo around the way I actually move files: open the app, click a saved server, see local and remote files side by side, and start transferring.

## What it does

- Connect to **FTP, FTPS (TLS) and SFTP (SSH)** servers.
- Browse your Mac and the remote server side by side.
- Upload and download files with drag and drop.
- Save server passwords in **macOS Keychain**.
- Import saved connections from FileZilla and export them back.
- Export and restore Molo server backups.
- Automatically back up saved server connections to **iCloud Drive** in the website edition.
- Keep connections open when switching servers, with automatic reconnection after interruptions.
- Browse, rename and manage remote files and folders.

Molo is written in SwiftUI for Apple Silicon. It supports English, Slovak, Czech, Hungarian, German, Russian and Ukrainian.

## Requirements

- Apple Silicon Mac: M1 or newer
- macOS 14 or later
